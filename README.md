## 🌐 Trải Nghiệm Trực Tuyến & Tính Năng Nổi Bật

Trang web được thiết kế theo phong cách hiện đại với nhận diện thương hiệu SunnyCare:
- **Tone màu chủ đạo**: `#1992b0` (Xanh ngọc thương hiệu) & `#ff9500` (Cam ấm áp, điểm nhấn chuyển hóa).
- **Aceternity Floating Navbar Menu**: Thanh điều hướng dạng viên thuốc (pill) nổi với hiệu ứng kính mờ (`backdrop-blur-md`).
- **Aceternity Collapsible Sidebar dạng Sơ Đồ Cây (Tree View)**: Thư mục Thư tín có thể mở/đóng với các nhánh nối (branch lines) dẫn trực tiếp vào từng bức thư.
- **Aceternity Animated Buttons**: Hiệu ứng Shimmer button và Border-glow xoay 360°.
- **Dẫn hướng liên hoàn (Next Step Journey)**: Mỗi bức thư đều có nút bấm chuyển tiếp mượt mà sang thư kế tiếp.
- **Tối ưu in ấn (Print / Export PDF)**: Chuẩn hóa xuất file PDF tài liệu A4 cho từng phiên.

## 🚀 Kích Hoạt GitHub Pages (Xem Trực Tuyến Miễn Phí)

Để đưa website lên trực tuyến cho thân chủ đọc trên điện thoại/máy tính:
1. Truy cập vào repository trên GitHub: [paultran190521-cmd/huyen-phuong](https://github.com/paultran190521-cmd/huyen-phuong).
2. Vào **Settings** (Cài đặt) > chọn tab **Pages** ở thanh bên trái.
3. Tại mục **Build and deployment** > **Branch**:
   - Chọn nhánh: `main`
   - Chọn thư mục: `/ (root)`
   - Nhấn **Save**.
4. Chờ 1–2 phút, website sẽ hoạt động tại đường dẫn:
   👉 **`https://paultran190521-cmd.github.io/huyen-phuong/`**
